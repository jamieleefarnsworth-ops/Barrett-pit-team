BARRETT PIT CREW — PWA REBUILD

Upload all six web files from this ZIP into the ROOT of your existing GitHub Pages repository, replacing index.html, manifest.webmanifest, sw.js, and icon-192.png/icon-512.png, and adding icon-maskable-512.png. README.txt is optional.

Do not delete Chrome site data or local storage. The existing storage key car10_test_v1 is deliberately preserved to retain saved data on the same origin/browser. Export a JSON backup before changing files.

The app works in a browser and can be used offline after the service worker installs. Whether Android allows standalone installation depends on the browser/OS WebAPK installation service and Play Protect; changing the website cannot guarantee that it will install.
